# Limpaí Estofados & Auto

React + Vite. Rodar: `npm install` e `npm run dev`. Build: `npm run build`.
Vercel: importe o repositório (framework Vite, build `npm run build`, saída `dist`).

O arquivo `vercel.json` configura cabeçalhos HTTP de segurança para as publicações no
Vercel. Após alterações, publique uma nova versão. Proteja também as contas do GitHub e
Vercel com autenticação em dois fatores, limite os colaboradores e não compartilhe
tokens de acesso; esses controles não podem ser aplicados pelo código do site.

Edite tudo em `src/config.js`: número do WhatsApp (`WHATSAPP_NUMBER`), textos, FAQ,
avaliações e imagens. A seção “Antes e Depois” exibe as seis fotos completas em
`public/images/antes-depois-1.png` a `public/images/antes-depois-6.png`.
